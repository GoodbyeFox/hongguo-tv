# 红果短剧 v0.2.141

本次重点修复播放取源接口返回空响应（`VIDEO_MODEL_EMPTY`）的问题。Android 标准版、MPV 版、macOS / Windows、Linux AppImage 测试版和 webOS 测试版均从同一主线版本构建。

- 播放取源请求补上签名。上游对无签名的 `multi_video_model` 请求返回 HTTP 200 空正文，0.2.140 的匿名身份更换对此无效；Go 核心和 webOS 独立服务复用项目已有的完整签名算法，不引入外部签名服务或新依赖。
- 保留有界兼容回退：每个身份最多三次请求，依次为签名原主机 → 签名官方备用主机 `api5-normal-hl.fqnovel.com` → 原主机的原有无签名请求；连续空响应后的身份更换和总请求预算不变，不会无限重试。
- 账号签名、播放 UA、分集 ID、codec 筛选和媒体处理保持不变。
- Android 标准版从 Media3 回到 HTML5 时保留音量和静音状态，避免切换过渡时的临时静音被误当作用户设置。
- 预取分集的加载提示分阶段显示，减少切集时的提示闪动。
- 云端 CI 增加签名请求实播验证：只有签名请求能取得真实片源。
